# LogicArrows

Программы на ассемблере для компьютеров из логических стрелок Аркадия Чубрика.

## Компьютеры

Оригинальные схемы, документация и примеры программ находятся в
[репозитории chubrik/LogicArrows](https://github.com/chubrik/LogicArrows):

- [Computer v1 — первая версия компьютера](https://github.com/chubrik/LogicArrows/tree/main/computer-v1).
- [Computer v2 — вторая версия компьютера](https://github.com/chubrik/LogicArrows/tree/main/computer-v2).

## Использование

1. Загрузите готовую дискету в Computer v2 и запустите программу.
2. После `>` введите текст; **Backspace** удаляет последний символ только в текущей строке.
3. Нажмите **Enter**, чтобы вычислить и вывести QR. Пустой ввод игнорируется.
4. После вывода появляется новое `>`; перезапуск компьютера не нужен.
5. **Esc** очищает весь терминал и буферы, затем выводит новое `>` без генерации QR.

В Python-эмуляторе клавиша Esc должна передавать код `0x1B` в порт `0x3E`.
Для эмулятора без этой обработки добавлен [патч Esc](computer-v2/patches/emulator-escape.patch).
Примените его из папки эмулятора командой `git apply /путь/к/emulator-escape.patch`.

Исходник можно собрать компилятором **Computer v2**.

## Память и ограничения

Образ занимает **864 из 1024 байт**, свободно **160 байт**:
инструкции — 568, постоянные таблицы — 115, рабочие области и порты — 98,
заполнение банков — 83 байта. Полная изменяемая матрица QR в RAM не хранится.

- **Только Version 1-L, 21×21**, Byte mode с ECI 22 (CP1251).
- **Маска фиксирована: 0**. Перебора масок и расчёта штрафов нет.
- Автоматического выбора размера и уровня коррекции в этой сборке нет.
- CPU вычисляет данные и 7 байт ECC. Коэффициенты Reed–Solomon и служебный
  шаблон подготовлены при сборке.
- Вывод идёт в **терминал**, а не на дисплей 16×16. Внешнее поле шириной
  четыре модуля программа не добавляет.
- Перенос после 12 столбцов выполняет терминал. Знак `>` занимает первый
  столбец, поэтому первая строка вмещает 11 символов ввода. На границе
  переноса Backspace игнорируется: символы предыдущей строки сохраняются
  и на экране, и в буфере. Для полного сброса ввода используйте Esc.

## Проверка

Программа проверена Python-эмулятором: ввод длиной 0...16 символов,
защита Backspace на границе переноса, очистка всех строк по Esc и повторная
генерация QR. Для 16 сообщений графический вывод совпадает с прежней версией.
Размер образа — 864 байта; сборки официального и Python-компилятора совпадают.
