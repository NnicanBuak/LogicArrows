# 3DEditor для Computer v2

**Статус: проектирование.** Редактор вершин, рёбер и граней на основе управления и демонстрационной модели [3DViewer](../3dviewer/README.md). Лимит полного машинного образа — **32 КБ (32768 байт)**, включая код, геометрию и рабочие буферы. Исполняемый исходник, скомпилированная дискета и демонстрация появятся после реализации.

**Зависимость: [API 3DGraphics](../graphics3d/API.md)** и [общий модуль ASM](../graphics3d/engine.asm). Движок отвечает за проекцию и отрисовку модели; редактор добавляет навигацию по элементам, список выбранного, изменение геометрии и терминальный ввод.

## Подсветка и выбор

| Цвет | Значение |
|---|---|
| **Фиолетовый** | Обычная геометрия модели |
| **Красный** | Текущий элемент под курсором, доступный для выбора |
| **Синий** | Элементы в списке выбранных для редактирования |

**Подсвеченный элемент и выбранный элемент — разные состояния.** Перемещение курсора меняет красную подсветку. Enter добавляет текущий элемент в список выбранных. Трансформации и удаление действуют только на этот список.

Для совпадающих пикселей приоритет — **красный → синий → фиолетовый**. Если курсор находится на уже выбранном элементе, элемент выглядит красным и остаётся в списке. После ухода курсора он становится синим. Цвет подсветки заменяет оба цветовых бита пикселя: красные и синие элементы при наложении сохраняют приоритетный цвет.

В режиме вершин подсвечиваются точки, в режиме рёбер — отрезки, в режиме граней — соответствующая поверхность или её контур. Способ отображения граней уточняется при реализации.

## Основное управление

| Клавиша | Действие |
|---|---|
| **1** | Выбор вершин |
| **2** | Выбор рёбер |
| **3** | Выбор граней |
| **← / ↑ / → / ↓** | Переместить курсор к ближайшему элементу в направлении стрелки |
| **Enter** | Добавить текущий элемент в список выбранных |
| **g** | Начать перемещение выбранных элементов |
| **r** | Начать поворот выбранных элементов |
| **s** | Начать масштабирование выбранных элементов |
| **Del** | Удалить выбранные элементы |
| **Esc** | Сбросить выбор; внутри инструмента — отменить текущую трансформацию |

Каждое нажатие **1, 2 или 3** очищает весь список выбранных и устанавливает курсор на ближайший элемент нового типа к прежнему положению курсора. При отсутствии элементов этого типа список и курсор пусты.

Все буквенные команды вводятся **латиницей в нижнем регистре**. Клавиши нажимаются последовательно; Ctrl и Shift для инструментов не требуются. В финальной программе сброс и отмена закреплены за **Esc**. Клавиша **q свободна**. В тестовом адаптере эмулятора другая клавиша может передавать код Esc (`0x1B`), не меняя управление самой программы.

## Относительные трансформации

Последовательность: **выбрать элементы → нажать g/r/s → ввести ось, необязательный знак и число → Enter**. После подтверждения программа возвращается к выбору, сохраняя список выбранных. Esc отменяет текущую трансформацию и возвращает выбор; следующее Esc очищает список.

В терминал вводится одна строка **без пробелов**: `x2`, `x+2`, `y-15`, `z0.5`. Допустимые оси — **x, y, z**. Положительный знак можно опустить. Дробная часть отделяется точкой. Перед вводом терминал показывает текущие значения **X/Y/Z** и активный инструмент. Backspace исправляет строку.

| Инструмент | Строка в терминале | Результат |
|---|---|---|
| **g** | `x2` или `x+2` | Прибавить 2 к текущему положению по X |
| **g** | `x-2` | Прибавить −2 к текущему положению по X |
| **r** | `z90` | Прибавить поворот на 90° вокруг Z к текущему состоянию |
| **r** | `y-15` | Повернуть текущее состояние на −15° вокруг Y |
| **s** | `x2` | Умножить текущий размер по X на 2 |
| **s** | `x0.5` | Умножить текущий размер по X на 0,5 |
| **s** | `x-2` | Отразить относительно центра по X и увеличить размер вдвое |

Новые операции применяются к **текущей геометрии**. Два перемещения `x2` дают суммарное смещение +4; два масштабирования `x2` увеличивают размер вчетверо.

Трансформации ребра изменяют его конечные вершины, трансформации грани — её вершины. Общая вершина нескольких выбранных деталей изменяется **один раз за операцию**. Соседние детали, использующие эту вершину, также меняют форму.

Ввод фильтруется. Неправильный формат, неподдерживаемая точность, переполнение и выход итоговых координат за допустимый диапазон дают **ошибку без частичного изменения модели**. Числовые диапазоны, точность, центр преобразований и порядок сочетания поворотов будут зафиксированы до реализации математической части.

## Удаление и целостность модели

Del действует на **выбранные** элементы. Одна красная подсветка при пустом списке не запускает удаление.

Предлагаемое правило сохранения целостности:

- При удалении вершины удалять связанные с ней рёбра и грани.
- При удалении ребра удалять грани, для которых оно служит границей; вершины сохранять.
- При удалении грани сохранять её вершины и рёбра.
- После удаления очищать список и устанавливать курсор на ближайший оставшийся элемент.

## Использование API 3DGraphics

Предполагаемый цикл кадра: **`gfx_begin` → проекция и рисование геометрии → применение масок подсветки → `gfx_present`**. Проекция вершин и примитивы отрисовки используются через API; маски выбранных элементов и курсора обеспечивают приоритет цветов.

Текущие `gfx_move`, `gfx_rotate` и параметры масштаба API относятся ко **всему активному объекту**. Редактирование части модели требует отдельного изменения её вершин в RAM. Управление ракурсом и зумом будет отделено от редактирования геометрии.

Полный API сейчас задаёт вращение объекта в 32 положениях с шагом **11,25°** и единый масштаб Q5. Ввод углов в градусах и масштабирование по отдельным осям требуют согласования формата данных редактора с возможностями движка. Эти ограничения будут отражены в сообщениях терминала и проверках ввода.

## Дополнительные предложения

Следующие элементы управления обсуждены как предложения и ещё не закреплены:

- **Повторный Enter** — убрать текущий элемент из списка.
- **Tab** — перебрать элементы по порядку, включая совпадающие на экране.
- **i/k и j/l** — поворачивать ракурс; **+/= и −** — менять зум изображения шагом **0,2** в пределах **×0,5…×3**.
- **p** — переключать центр вращения и масштабирования между центром выбранных вершин и началом координат.
- **n** — создавать вершину; **f** — создавать ребро из двух или грань из трёх/четырёх выбранных вершин.
- **u** — отменять последнее завершённое изменение.

Вместимость модели, способ экспорта и сохранения, точные пределы чисел и правила создания граней требуют отдельной фиксации. Дисплей **16×16** и терминал **12×4** ограничивают объём информации, видимой одновременно; номера элементов помогут различать совпадающие проекции.

## Критерии реализации и проверки

- Полный образ **≤32768 байт**, безопасные обращения к памяти.
- Явное различие курсора и списка выбранных, сброс списка при смене режима.
- Приоритет цветов без смешивания красной и синей подсветки.
- Относительный ввод **g/r**, умножение для **s**, поддержка отрицательного множителя.
- Изменение каждой общей вершины один раз, сохранение целостности связей после удаления.
- Проверка формата и диапазонов до применения операции, отсутствие частичных изменений при ошибке.
- Финальные **Esc** и свободная **q**; тестовое переназначение находится только в адаптере эмулятора.
- Совпадение геометрии и пикселей с независимым расчётом, рабочая дискета и демонстрация после реализации.
