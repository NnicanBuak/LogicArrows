# Общий эмулятор Computer v2

Запускает ASM-программы из этого репозитория. Память — **32 КБ**, дисплей — **16×16**, рядом — терминал. По умолчанию размер терминала **12×4 символа**; размеры истории можно задавать при запуске. Строка ввода располагается отдельно от истории.

## Запуск

Установи **Python 3.10 или новее**. Скачай репозиторий целиком и открой терминал в его корневой папке.

Один раз установи зависимость:

```sh
python -m pip install -r emulator/requirements.txt
```

Запусти эмулятор:

```sh
python emulator/run.py
```

Нажми **F4** и выбери файл **.asm**. Программа начнёт выполняться сразу. Исходник компилируется при открытии.

Можно сразу указать программу:

```sh
python emulator/run.py 3deditor/3deditor.asm
python emulator/run.py graphics3d/build/cube/graphics3d.asm
python emulator/run.py 3dviewer/3dviewer.asm
```

Размер терминала задаётся как `ШИРИНАxВЫСОТА` в символах. Например, окно с историей 24×9 и отдельной строкой ввода:

```sh
python emulator/run.py 3deditor/3deditor.asm --terminal-size 24x9
```

Чтобы скрыть дисплей 16×16 и отдать основную область терминалу, добавь `--hide-display`:

```sh
python emulator/run.py 3deditor/3deditor.asm --terminal-size 24x9 --hide-display
```

Для проекта, который формирует графические символы терминала из полноразмерного кадра, можно подключить рендерер:

```sh
python emulator/run.py 3deditor/3deditor.asm --terminal-size 24x9 --hide-display --terminal-renderer 3deditor-terminal/renderer.py
```

Символы эмулятора — **6×8 пикселей**; окно показывает их в масштабе 4×, то есть по **24×32 пикселя** на символ. Размер окна подстраивается под выбранные размеры терминала.

## Управление

| Клавиша | Действие |
|---|---|
| **F1** | Пауза / продолжить |
| **F2** | Запустить текущий исходник заново; данные в памяти сбрасываются |
| **F3** | Пауза и один шаг процессора |
| **F4** | Открыть другой ASM-файл |
| **F7 / F8** | Уменьшить / увеличить скорость вдвое |
| **Стрелки, Enter, Tab, Backspace, Del, Esc, буквы и знаки** | Передать программе |
| **Закрыть окно** | Завершить эмулятор |

Программа управляет изображением и текстом в терминале. Её клавиши описаны в README соответствующего проекта. Ввод передаётся по очереди, чтобы быстрый набор не терялся во время вычислений.

### Сохранить модель 3DEditor

В [3DEditor](../3deditor/README.md) **F5** сохраняет модель в `saved.model.json` рядом с ASM, **F6** загружает её. После загрузки включается редактирование вершин. Пока открыт gizmo, сохранение и загрузка заблокированы.

Сначала нажми **F5**, затем перезапусти программу и нажми **F6**, чтобы продолжить работу с моделью. Можно указать другой файл:

```sh
python emulator/run.py 3deditor/3deditor.asm --model my-model.json
```
