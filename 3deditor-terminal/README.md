# 3DEditor Terminal

Отдельная ASM-версия клавиатурного 3D-редактора для Computer v2. Она рисует модель **процессором программы** и напрямую выводит кадр **144×72 пикселя** через графический порт терминала: **24×9 символов**, по **6×8 пикселей** каждый. Строка ввода эмулятора расположена отдельно от кадра. Обычный [3DEditor](../3deditor/README.md) не меняется.

## Запуск

Из корня репозитория:

```sh
python 3deditor-terminal/run.py
```

Команда загружает `3deditor-terminal.asm` в обычный эмулятор Computer v2 с терминалом 24×9 и скрытым LCD 16×16. Кадр выводится самим ASM через порт терминала. Управление и горячие клавиши совпадают с [обычным 3DEditor](../3deditor/README.md).

## Сборка

Из корня репозитория пересоберите ASM-исходник, затем скомпилируйте его официальным ассемблером Computer v2:

```sh
python 3deditor-terminal/build.py
node qr-terminal-v2/tools/compile.mjs 3deditor-terminal/3deditor-terminal.asm
```

Первый шаг собирает `3deditor-terminal.asm` из нативного ASM-ядра, API `3DGraphics` и байткода редактора. Второй — проверяет ASM и создаёт исполняемый образ, текст дискеты и отчёт компиляции.

## Состав

| Файл | Назначение |
|---|---|
| [3deditor-terminal.asm](3deditor-terminal.asm) | Исполняемый исходный код Computer v2 ASM |
| [3deditor-terminal.diskette.txt](3deditor-terminal.diskette.txt) | Скомпилированная дискета Computer v2 |
| [3deditor-terminal.bin](3deditor-terminal.bin) | Бинарный образ программы |
| [run.py](run.py) | Запуск в обычном эмуляторе с терминалом 24×9 |
| [build.py](build.py) | Генератор ASM-исходника |
| [native_runtime.py](native_runtime.py) | Нативное ASM-ядро редактора и терминального вывода |

Кадр монохромный. Модель и вершины занимают область 144×72; выбранный объект помечается маркером, активный элемент — перекрестием. Эмулятор выводит кадр штатно из байтов, записанных программой в порт `0x3D`, без Python-рендерера.
