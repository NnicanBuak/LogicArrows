# 3DEditor Terminal

Клавиатурный 3D-редактор, полностью выводящий сцену в терминал. Кадр **144×72 пикселя** складывается из **24×9 графических символов** Computer v2; каждый символ кодирует собственный блок **6×8 пикселей**. Строка состояния и ввода расположена отдельно под кадром.

## Запуск

Из корневой папки репозитория:

```sh
python -m pip install -r emulator/requirements.txt
python 3deditor-terminal/run.py
```

Управление, моделирование, история отмены и F5/F6 используют исходную программу [3DEditor](../3deditor/README.md). Python-рендерер читает текущее состояние модели и камеры из её памяти, строит кадр в полном разрешении и передаёт графические символы через порт терминала **0x3D**. Экран LCD 16×16 в этом проекте не отображается.

## Вывод кадра

Терминал Computer v2 хранит каждый графический символ как шесть столбцов по восемь пикселей. Рендерер делит каждый кадр на **9 строк по 24 символа**, кодирует каждый блок 6×8 и отправляет его в терминал построчно. Модель и инструменты рисуются из геометрии текущей модели, не из увеличенного кадра 16×16.

Графические символы одноцветные: контуры, заливка, выбранные детали и курсор различаются толщиной, штриховкой и миганием. Клавиши и инструменты описаны в [README 3DEditor](../3deditor/README.md).
