## Заменить компактную модель

Откройте ASM нужной каркасной программы и найдите секцию `model`. Данные идут подряд:

1. Число вершин V и рёбер E — два байта.
2. V троек координат `X₂,Y₂,Z₂` в половинах единицы.
3. E пар байтов `a | (color << 6), b`.

Индексы начинаются с нуля. Цвета: **1 — красный, 2 — синий, 3 — фиолетовый**. Знаковые координаты записываются дополнительным кодом: `255` означает −1 в записанных единицах, то есть −0,5 в координатах модели.

Измените счётчики, вершины и соединения рёбер. Вычислительная часть расположена перед моделью и занимает **896 байт**. Размер данных равен `2 + 3V + 2E`.

## Заменить модель полного API

Геометрия начинается в банке `MODEL_BASE` с адреса 128. Заголовок содержит три байта `V,E,T`; далее расположены XYZ вершин, трёхбайтовые рёбра и четырёхбайтовые треугольники.

Для каркаса задайте `T=0`. Для заполненных поверхностей задайте треугольники с цветами. У готовых полигональных программ `E=0` и включён `STATE_CULL=1`: CPU отсекает обратные грани и рисует передние треугольники от дальних к ближним.

Размер геометрии равен `3 + 3V + 3E + 4T`. Экранные вершины используют `4V` байт начиная с `VERTEX_BASE`, рабочие записи треугольников — `5T` байт начиная с `TRI_BUFFER_BASE`.

Секции ASM размещаются банками по 128 байт. После изменения данных обновите заполнение секций и константы расположения областей. Метки и комментарии `Банк памяти #N` задают адреса и банки подпрограмм.

## Изменить вращение и размер

В полном API `yaw`, `pitch` и `roll` задают повороты вокруг Y, X и Z. Один шаг угла равен **11,25°**. Параметры кадра вычисляются в `frame_start`; для постоянного ракурса передайте выбранные значения углов.

`frame_scale` записывает коэффициент Q5 в `STATE_SCALE`: **32 — ×1, 48 — ×1,5, 64 — ×2**. Собственное приложение также может устанавливать коэффициент через `gfx_set_scale`. Масштаб применяется к XYZ перед вращением.

Компактные каркасные программы используют `phase` для вращения вокруг Y и `pulse_phase` для пульсации размера. Параметр `scale` хранит коэффициент 64…128, соответствующий размеру ×1…×2.

## Изменить куб Cube16

| Параметр | Место в ASM |
|---|---|
| Высота | `vertex_calc`, значение 3 перед меткой `y_positive` |
| Направление вращения | `frame_complete`, обновление `phase` |
| Размер по горизонтали | Амплитуда 32 значений таблицы `sine` |
| Соединение вершин | Двенадцать пар индексов в таблице `edges` |

Cube16 занимает **1022 байта**. Программы полного API занимают **16 640…16 896 байт (>1 КБ)**; размеры отдельных демонстраций приведены рядом с исходниками и дискетами в README.
