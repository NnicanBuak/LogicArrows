# 3DGraphics: компактные каркасные программы

Один движок преобразует вершины XYZ и рисует цветные рёбра на экране **16×16**. Модель вращается вокруг Y, размер пульсирует **×2 → ×1 → ×2** за 256 кадров.

## Данные модели

Общий код занимает **896 байт**. Секция `model` содержит заголовок `V,E`, V троек знаковых координат в половинах единицы и E пар байтов `a | (color << 6), b`.

Первый индекс ребра занимает младшие шесть битов, цвет — старшие два. Индексы начинаются с нуля; цвета 1, 2 и 3 соответствуют красному, синему и фиолетовому. Размер геометрии равен `2 + 3V + 2E`.

Над фигурами в GIF указан объём данных модели. Модель задаётся вершинами и рёбрами; общий код вычисляет проекцию и анимацию во время исполнения.

Кадр строится в 64 байтах LCD RAM при отключённом обновлении дисплея. После завершения отрисовки программа включает цветной режим и повторно записывает все готовые байты.
